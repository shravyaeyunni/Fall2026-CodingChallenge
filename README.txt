Collect is a full-stack image discovery and organization application built with React, Node.js,
and Express. Users can discover images through the Pixabay API, curate personalized collections,
edit and organize saved content, and share their collections through links.

========================================
               HOW TO RUN
========================================

1. Make sure Node.js and npm are installed.

2. Clone or download this repository and open the project folder.

3. Set up and start the backend:

   cd backend
   npm install

   Create a .env file in the backend folder containing:

   PIXABAY_API_KEY=pixabay_api_key_here

   Then start the backend server:

   node server.js

4. Open a second terminal and start the frontend:

   cd frontend
   npm install
   npm run dev

5. Open the local URL provided by Vite in your browser.

Keep both the frontend and backend servers running while using the application.
